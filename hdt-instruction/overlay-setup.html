Mod のインストール websocket-sharp をインストールする 使用する Mod マネージャーに応じてインストール Mod Assistant の場合 Mod Assistant を起動し、Mod タブを開く Libraries グループにある websocket-sharp を選択する 右下の Install or Update ボタンを押して、インストールする BSManager の場合 BSManager を起動し、対象のバージョンを選択する Mods タブを開き、websocket-sharp を検索する websocket-sharp をインストールする HttpSiraStatus のダウンロードと配置 HttpSiraStatus のダウンロード Beat Saber のバージョンに応じてダウンロード Beat Saber 1.42.0 の場合 → 未確認 現時点では Beat Saber 1.42.0 のための HttpSiraStatus のリリースはありません。
対応状況は Github リリースページ の最新版を利用するなどして確認してください。 Beat Saber 1.40.8 の場合 → HttpSiraStatus 14.1.0 Github から zip ファイルをダウンロード。
(HttpSiraStatus-14.1.0-bs1.40.0-795ace9.zip) Beat Saber 1.39.1 の場合 → HttpSiraStatus 13.0.0 Github から zip ファイルをダウンロード。
(HttpSiraStatus-13.0.0-bs1.39.0-d31233e.zip) Beat Saber 1.37.1 の場合 → HttpSiraStatus 12.0.2 Github から zip ファイルをダウンロード。
(HttpSiraStatus-12.0.2-bs1.37.1-27f5e15.zip) Beat Saber 1.29.1 の場合 → HttpSiraStatus 9.1.0 Github から zip ファイルをダウンロード。
(HttpSiraStatus-9.1.0-bs1.29.0-626dccb.zip) ダウンロードした zip ファイルを解凍 解凍したファイルを Plugins フォルダへ移動

解凍して現れた Plugins\HttpSiraStatus.dll を Beat Saber のインストールディレクトリにある Plugins フォルダにコピー

Beat Saber のインストールパスが下記の場合
C:\Program Files (x86)\Steam\steamapps\common\Beat Saber
コピー後の HttpSiraStatus.dll が下記の場所に存在する状態となる。
C:\Program Files (x86)\Steam\steamapps\common\Beat Saber\Plugins\HttpSiraStatus.dll 不要なファイルを削除する Mod の干渉を防ぐため、もし Beat Saber の Plugins フォルダに下記のファイルがあれば、それを削除する。
  • BeatSaberHttpStatus.dll
  • HttpStatus.dll
 オーバーレイの動作確認 この手順を行うには MultiplayerPlus がインストールされている必要があります。
MultiplayerPlus が未導入の場合、オーバーレイは失敗表示になりますが、 「HttpSiraStatus を検出できません」というメッセージが表示されなければ、Mod の導入自体は成功しています。 Beat Saber を起動する

VR HMD を使わずにデスクトップで起動しても、オーバーレイの表示確認は可能です。

デスクトップで起動する場合は、起動方法に応じて下記のいずれかの方法で起動してください。

デスクトップでの起動方法 Steam から起動する場合 Steam ライブラリの Beat Saber を右クリックし、プロパティを開き、起動オプション に fpfc を追加して起動する。 BSManager から起動する場合 BSManager の対象バージョンの Launch タブから Launch Options を開き、FPFC Mode にチェックを入れて起動する。 Web ブラウザでオーバーレイの URL を開く

下記の URL を Web ブラウザで開く。
https://garai.dogesato.com/public/tournament/index.html

表示を確認する 表示内容に応じて確認 成功の場合 下記のような表示であれば、Mod の導入は正しく完了しています。 この後のオーバーレイ動作確認へ進んでください。 失敗の場合 下記のような表示の場合、Mod の導入が正しく行われていません。上記の手順を見直してください。
もしやり直しても解決しない場合は、大会運営者などに相談してください。 オーバーレイの動作確認 試しに任意の譜面をプレイし、オーバーレイにスコアやコンボが反映されるか確認してください。
