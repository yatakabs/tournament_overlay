C:\Program Files (x86)\Steam\steamapps\common\Beat Saber
After copying, confirm the file exists here:

  • BeatSaberHttpStatus.dll
  • HttpStatus.dll
 Verify the Overlay Prerequisite: Install MultiplayerPlus.
If MultiplayerPlus is not installed, the overlay may show a failure screen. In that case, treat the mod setup as successful as long as you do not see: HttpSiraStatus を検出できません Start Beat Saber

You can verify the overlay in desktop mode (without a VR headset).

To start in desktop mode, use one of the options below.

Desktop-mode launch options Steam In Steam, right-click Beat Saber → Properties → Launch Options, then add fpfc. BSManager In BSManager, open the target version's Launch tab → Launch Options, then enable FPFC Mode. Open the overlay page in a web browser

Open the following URL:
https://garai.dogesato.com/public/tournament/index.html

Confirm the page is working What do you see? Success If you see a screen like this, the mods are installed correctly. Next, do the in-game overlay check below. Failure If you see a screen like this, the overlay is not receiving data. Re-check the steps above.
If retrying does not help, please contact the tournament staff. The error message on screen tells you what is missing:
  • HttpSiraStatus を検出できません — HttpSiraStatus is not installed or not loaded. Go back to Step 1-2 and re-install it.
  • MultiplayerPlus を検出できません — MultiplayerPlus is not installed. This mod is required for the tournament overlay to work. Install it before continuing.
 Confirm live updates in-game Play any song and check whether the score/combo updates on the overlay.
If you can see score/combo updating like this, the setup is complete.
